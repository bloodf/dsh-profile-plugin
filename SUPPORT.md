# Support

## Getting Help

### Documentation

Start with the [README](./README.md) — it covers installation, configuration, OAuth setup, architecture, and troubleshooting.

### Issues

If you've found a bug or have a feature request, [open an issue](https://github.com/deepseek-ai/plugins/issues/new/choose) using the appropriate template.

### Discussions

For questions, ideas, and general conversation, use [GitHub Discussions](https://github.com/deepseek-ai/plugins/discussions) if available, or open an issue tagged with `question`.

### DeepSeek Harness

For issues with the Harness platform itself (not this plugin), see the [DeepSeek Harness repository](https://github.com/deepseek-ai/deepseek-harness).

## What to Include in a Support Request

1. **Node.js version** (`node --version`)
2. **Harness version** (`dsh --version`)
3. **Plugin version** (from `package.json`)
4. **Steps to reproduce** the issue
5. **Error messages** or logs (redact credentials)
6. **Expected vs. actual behavior**

## Security Issues

Do **not** open a public issue for security vulnerabilities. See [SECURITY.md](./SECURITY.md) for private reporting instructions.
